# Менеджер задач

Task Manager — веб-приложение на Python и Django для управления задачами. Пользователи могут регистрироваться, создавать задачи, назначать исполнителей, присваивать статусы и метки, а также фильтровать список задач.

Демо: https://python-project-52-o8sp.onrender.com

## Стек технологий

- Python
- Django
- PostgreSQL (на продакшене) и SQLite (локально)
- django-filter
- Tailwind CSS (через django-tailwind-cli)
- WhiteNoise и Gunicorn
- Sentry SDK и Bugsink для отслеживания ошибок
- uv и Ruff

## Установка и запуск

### 1. Клонирование репозитория

Убедитесь, что у вас установлены Git, Python 3.10 или новее и `uv`. Node.js и npm не нужны: исполняемый файл Tailwind скачивается автоматически.

```
git clone https://github.com/Ainur2006/python-project-52.git
cd python-project-52
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта:

```
SECRET_KEY=your-secret-key
DEBUG=True
```

`SECRET_KEY` используется Django для защиты сессий и форм. Для локальной разработки укажите собственное случайное значение. По умолчанию приложение использует SQLite. Чтобы подключить PostgreSQL, добавьте строку подключения:

```
DATABASE_URL=postgresql://username:password@localhost:5432/task_manager
```

Чтобы включить отправку ошибок в Bugsink, добавьте DSN (необязательно):

```
SENTRY_DSN=your-dsn
```

### 3. Установка зависимостей, сборка стилей и миграции

```
make setup
```

Команда устанавливает зависимости, собирает стили Tailwind CSS, статические файлы и применяет миграции.

### 4. Создание администратора (по желанию)

```
uv run python manage.py createsuperuser
```

### 5. Запуск приложения

```
make dev
```

После запуска откройте в браузере: http://127.0.0.1:8000

## Возможности

- Регистрация, вход и выход пользователей.
- Просмотр, изменение и удаление пользователей (менять и удалять можно только свой профиль).
- Управление статусами задач.
- Управление метками.
- Создание, просмотр, изменение и удаление задач. Удалить задачу может только её автор.
- Фильтрация задач по статусу, исполнителю, метке и по принадлежности пользователю.
- Защита от удаления статусов, меток и пользователей, связанных с задачами.
- Отправка ошибок продакшена в Bugsink.
